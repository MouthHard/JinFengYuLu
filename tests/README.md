# 测试说明

## 测试结构

这个项目采用精简的测试策略，专注于测试核心工具函数。

```
tests/
├── utils.spec.ts      # 核心工具函数测试
├── components.spec.ts # 组件渲染测试
└── README.md          # 本文件
```

## 运行测试

```bash
# 运行所有测试（监听模式）
npm test

# 运行所有测试（一次性）
npm run test:run
```

## 测试策略

### 测试范围
1. **核心工具函数** - 纯函数，易于测试且有实际价值
2. **关键组件** - 简单的挂载测试

### 不测试的内容
- UI 交互细节（通过人工测试）
- 复杂的集成测试（对于静态网站价值不大）
- E2E 测试（Playwright 配置已移除）

## 添加新测试

1. 在 `utils.spec.ts` 中添加工具函数测试
2. 如果需要，在 `components.spec.ts` 中添加组件测试
3. 运行 `npm run test:run` 验证
