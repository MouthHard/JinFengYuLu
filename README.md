# 金风玉露

个人博客项目，平时想写点什么都往里面塞

## 技术栈

Vue 3 + TypeScript + Vite + Pinia

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 生产构建
npm run build
```

## 项目结构

```
src/
├── pages/      # 页面模块
├── components/ # 公共组件
├── stores/     # 状态管理
└── composables/
```

## 功能模块

-  诗词 - 搜索、分类、阅读
-  历史 - 时间线、人物、遗产
-  风景 - 摄影作品、旅行
-  博物馆 - 文物展示
-  音乐 - 古风音乐
-  游戏 - 互动体验
