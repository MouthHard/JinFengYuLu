> 最后更新: 2026-08-26

---

## 一、快速启动

### 1. 启动数据库

```bash
# 启动 MySQL 服务（Windows 服务）
# 或通过 XAMPP/MySQL Workbench 等工具启动

# 确认数据库运行
mysql -u root -p
```

### 2. 启动后端服务

```bash
# 进入后端目录
cd server

# 开发模式启动
npm run start:dev

# 或生产模式启动
npm run start
```

**端口**: 3000
**API 文档**: http://localhost:3000/api/docs

### 3. 启动前端服务

```bash
# 在项目根目录
npm run dev
```

**端口**: 5173
**访问地址**: http://localhost:5173

## 四、问题排查

### 后端无法启动

1. 检查 MySQL 是否运行
2. 检查端口占用: `netstat -an | findstr 3000`
3. 检查 .env 配置

### 前端无法访问 API

1. 确认后端服务已启动
2. 检查浏览器控制台错误

### 数据库连接失败

1. 确认 MySQL 服务已启动
2. 检查用户名和密码
