## 3. 通用迁移步骤

每个页面的迁移遵循 **7 步标准流程**：

```
Step 1: 设计数据库表结构 → server/database/<module>/schema/0X-xxx.sql
Step 2: 创建后端实体类   → server/src/entities/xxx.entity.ts
Step 3: 创建后端模块     → server/src/modules/xxx/
Step 4: 注册到 AppModule → server/src/app.module.ts
Step 5: 创建前端 API 文件 → src/api/xxx.ts
Step 6: 创建前端类型定义  → src/typesOfPages/xxx/
Step 7: 改造前端页面组件  → src/pages/Xxx/index.vue
```

### 通用文件创建模板

**数据库建表 SQL** (`server/database/<module>/schema/0X-xxx.sql`)：
```sql
CREATE TABLE IF NOT EXISTS `xxx` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT,
  -- 业务字段
  `is_active` TINYINT(1) DEFAULT 1 COMMENT '是否启用',
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  `updated_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

**后端实体** (`server/src/entities/xxx.entity.ts`)：
```typescript
import { Entity, Column, Index } from 'typeorm';
import { BaseEntity } from './base.entity';

@Entity('xxx')
export class Xxx extends BaseEntity {
  @Column({ type: 'varchar', length: 200 }) title: string;
  @Column({ name: 'is_active', type: 'tinyint', default: 1 }) @Index() isActive: boolean;
}
```

**后端 Controller** (`server/src/modules/xxx/xxx.controller.ts`)：
```typescript
import { Controller, Get, Query } from '@nestjs/common';
import { XxxService } from './xxx.service';

@Controller('xxx')
export class XxxController {
  constructor(private readonly xxxService: XxxService) {}

  @Get()
  findAll(@Query() query: QueryXxxDto) {
    return this.xxxService.findAll(query);
  }
}
```

**后端 Service** (`server/src/modules/xxx/xxx.service.ts`)：
```typescript
import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { Xxx } from '../../entities/xxx.entity';

@Injectable()
export class XxxService {
  constructor(
    @InjectRepository(Xxx) private xxxRepository: Repository<Xxx>,
  ) {}

  async findAll(query: QueryXxxDto) {
    const { page = 1, limit = 20 } = query;
    const [items, total] = await this.xxxRepository.findAndCount({
      where: { isActive: true },
      skip: (page - 1) * limit,
      take: limit,
      order: { id: 'DESC' },
    });
    return { items, total, page, limit, totalPages: Math.ceil(total / limit) };
  }
}
```

**后端 Module** (`server/src/modules/xxx/xxx.module.ts`)：
```typescript
import { Module } from '@nestjs/common';
import { TypeOrmModule } from '@nestjs/typeorm';
import { Xxx } from '../../entities/xxx.entity';
import { XxxController } from './xxx.controller';
import { XxxService } from './xxx.service';

@Module({
  imports: [TypeOrmModule.forFeature([Xxx])],
  controllers: [XxxController],
  providers: [XxxService],
})
export class XxxModule {}
```

**前端 API** (`src/api/xxx.ts`)：
```typescript
import { httpClient } from './request';

  const qs = new URLSearchParams(params).toString();
```

## 10. 前端开发注意事项

### 分类默认选中"全部"

当分类列表中有"全部"选项时，应默认选中第一个子分类（即"全部"），而不是跳过它选第二个。

**错误示例**：
```typescript
// ❌ 跳过了"全部诗词"，默认选中第二个
function pickFirstChild(children) {
  return children.find(c => c.name !== '全部诗词') ?? children[0];
}
```

**正确示例**：
```typescript
// ✅ 默认选中第一个（即"全部诗词"）
function pickFirstChild(children) {
  return children[0];
}
```

### CSS 样式注意事项

1. **避免使用 `background` 简写**：CSS 中 `background: #000000` 会同时设置 `background-image: none`，导致内联样式的 `background-image: url(...)` 失效。改用 `background-color`。

```css
/* ❌ 错误 */
background: #000000;
/* ✅ 正确 */
background-color: #000000;
```

2. **`<button>` 元素必须重置默认外观**：

```css
button {
  appearance: none;
  -webkit-appearance: none;
  border: 0;
  outline: none;
}
```

3. **Vue `:style` 绑定**：优先使用对象语法而非模板字符串，确保 Vue 正确渲染样式：

```vue
<!-- ❌ 可能出问题 -->
<div :style="`background: url(${imageUrl})`"></div>

<!-- ✅ 更可靠 -->
<div :style="{ background: `url(${imageUrl}) center/cover no-repeat` }"></div>
```

### 图片资源规范

1. 行星背景图等全局资源放在 `public/App/` 目录下
2. 使用 `import.meta.env.BASE_URL` 动态拼接路径，避免硬编码
3. 推荐使用 webp 格式减小体积
4. 在 `index.html` 中添加 `<link rel="preload">` 预加载关键图片
